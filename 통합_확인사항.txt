ImageEditor 기능 통합본

1. 기준 프로젝트
- ImageEditor_.zip의 .NET 6 WinForms 프로젝트를 기준으로 통합했습니다.
- 기존 SNS 비율, 미리보기, 보정, 필터, 레이어, 그리기, AI, 로그인, 타임라인 기능을 유지했습니다.

2. 추가·개선된 기능
- 그리기: 마우스 누름·이동·떼기 입력 안정화, 브러시 커서, 빠른 크기, 현재 레이어 지우기
- 레이어: 이미지 파일을 새 레이어로 추가
- 보정·기본 필터: DesignerUI의 카드형 보정 화면과 2열 필터 버튼 UI 적용, 자동 보정 제거
- 마스크: 기존 사각형 숨기기/복원 마스크를 제거하고 새 마스크 기능으로 교체
  (브러시/네모/동그라미 영역 지정, 영역 지우기·반전, 투명 지우기, 흑백, 흐림, 색상 반전, 효과 영역 뒤집기)
- 텍스트: 내용, 글꼴, 크기, 색상, 배경, 투명도, 스타일, 효과, 위치 조절 후 실제 레이어로 적용
- 템플릿: 폴라로이드, 필름, 매거진, 포토카드
- 커뮤니티 필터: 색감 프리셋, 하트, PNG 오버레이 이동·크기·회전
- 나만의 편집 스타일: 현재 밝기·대비·채도·색온도를 사용자별로 저장, 불러오기, 삭제
  (처음 사용할 때 MyEditStyle 테이블을 자동 생성하고, 적용 결과는 실행 취소와 타임라인에 포함)
- 실행 취소/다시 실행: Ctrl+Z, Ctrl+Y, 레이어·마스크 상태 포함
- 원본으로 돌아가기와 종료 메뉴 연결

3. 실행 전 확인
- Visual Studio 2022에서 ImageEditor.sln을 열고 NuGet 패키지를 복원한 뒤 실행하세요.
- 기존 Python 3.14 통합본을 이미 설치했다면 서버를 끈 뒤 이 수정본을 같은 폴더에
  덮어써도 됩니다. 새 .venv311 환경은 1_setup_server.bat로 설치합니다.
- 로그인/DB 기능은 MySQL imageeditor DB 연결 설정이 필요합니다.
- DB 기본값은 localhost:3306 / imageeditor / root / 1111입니다.
  다른 설정은 IMAGEEDITOR_DB_SERVER, IMAGEEDITOR_DB_PORT, IMAGEEDITOR_DB_NAME,
  IMAGEEDITOR_DB_USER, IMAGEEDITOR_DB_PASSWORD 환경 변수로 지정할 수 있습니다.
- 모든 AI 기능은 AIIntegratedServer의 단일 FastAPI 서버(127.0.0.1:8000)를 사용합니다.
- 먼저 Python 3.11.9 64-bit와 AI 패키지를 설치하고 3_start_server.bat로 서버를 직접 실행해야 합니다.
- AI 물체 제거와 배경 제거는 모델을 CPU로 직접 실행합니다.
  이 두 기능에는 API 토큰이나 크레딧이 필요하지 않습니다.
- 오래된 사진 복원은 Replicate 클라우드 GPU를 우선 사용하며, 실행마다 Replicate
  크레딧이 필요합니다. 오류가 나면 기존 로컬 CPU 복원으로 자동 전환합니다.
- 음악·자동 문구·게시글 추천은 Gemini API 키와 인터넷 연결이 필요합니다.
- AI 오래된 사진 복원은 Replicate FLUX Kontext로 손상·색상·얼굴·디테일을
  한 번에 처리하고, 실패 시 Zhang Colorization과 FSRCNN을 사용합니다.
- 세피아 단색 사진 판별과 선형 균열 마스크를 추가해
  복원 전후 차이가 거의 없던 문제를 수정했습니다.

4. 추천 확인 순서
- 이미지 열기
- 레이어 추가/삭제/순서/투명도
- 그리기와 지우개
- 새 마스크 기능
- 텍스트 적용
- 템플릿·커뮤니티 필터
- 로그인 후 보정 설정 변경 → 나만의 편집 스타일 저장/불러오기/삭제
- Ctrl+Z / Ctrl+Y
- AI > AI 오래된 사진 복원 → 복원 시작 → Before/After 확인 → 결과 적용
- AI > AI 배경 제거 → AI로 배경 제거 → 미리보기 확인 → 적용하기
- 저장·SNS 미리보기

5. AI 오래된 사진 복원 설정
- AIIntegratedServer/1_setup_server.bat로 패키지를 처음 한 번 설치합니다.
- 설치가 끝난 뒤 AIIntegratedServer/2_set_replicate_token.bat를 실행하고 토큰을 입력합니다.
- Replicate 복원은 인터넷과 크레딧이 필요하며 호출할 때마다 비용이 발생합니다.
- 오류가 나면 로컬 복원으로 바뀌며 비교 창에 실제 처리 방식이 표시됩니다.
- 취소 버튼으로 프로그램의 대기를 중단할 수 있습니다.

6. 통합 FastAPI AI 서버 설정
- 물체 제거는 MobileSAM과 LaMa, 배경 제거는 U2NetP를 사용자 PC의 CPU에서
  실행하며 사진 복원은 Replicate 클라우드 GPU를 우선 사용합니다.
- Python 3.11.9 설치 후 AIIntegratedServer/1_setup_server.bat를 한 번 실행합니다.
- ImageEditor를 사용하기 전에 AIIntegratedServer/3_start_server.bat를 실행하고
  서버 창을 열어 둡니다. 모델 다운로드를 위해 최초 실행에는 인터넷이 필요합니다.
- 그래픽카드가 없어도 실행되며, PC 성능과 이미지 크기에 따라 시간이 걸릴 수 있습니다.
- 연결이 안 되면 AIIntegratedServer/4_check_server.bat로 상태를 확인하세요.
- 물체 제거와 배경 제거에는 API 토큰과 호출료가 필요하지 않습니다.
- 사진 복원에는 Replicate 토큰과 크레딧이 필요합니다.
- 음악·자동 문구·게시글 추천은 선택 기능이며 Gemini API 키, 인터넷, Google의 요금/할당량이 적용됩니다.
- 배경 제거의 투명 배경을 유지하려면 결과를 PNG 형식으로 저장하세요.

7. 오류 수정
- CommunityFilterControl.resx의 바이너리 이미지 때문에 발생하던 MSB3821(웹 표시/인터넷 영역) 빌드 오류를 수정했습니다.
- 커뮤니티 필터 이미지는 안전한 PNG 임베디드 리소스로 분리했으며 기능과 원본 이미지는 그대로 유지됩니다.
- 프로그램을 처음 열면 로그인 창이 한 번 표시되며, DB를 쓰지 않을 때는 "로그인 없이 시작"할 수 있습니다.
- 새 로그인 코드가 기존 평문 비밀번호를 BCrypt 해시로 잘못 해석해 로그인이 실패하던 문제를 수정했습니다.
  기존 계정은 정상 로그인 후 비밀번호가 BCrypt 해시로 자동 전환됩니다.
- 로그인·회원가입·계정 찾기 쿼리를 매개변수 방식으로 바꾸고, 비밀번호 입력 숨김과 비밀번호 변경 화면을 추가했습니다.
- AI 배경 제거 미리보기에서 취소할 때 원본 화면으로 정상 복귀하도록 수정했습니다.
- 이미지 열기 후 작은 사진이 과도하게 확대되거나 MainForm 창 크기가 바뀌던
  문제를 수정했습니다.
