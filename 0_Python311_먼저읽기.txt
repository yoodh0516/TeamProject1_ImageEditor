Python 3.11.9 사용자용 실행 순서
================================

이 수정본은 Python 3.11.9 64-bit를 사용합니다.
다른 Python 버전의 가상환경과 분리되어 설치됩니다.

기존 Python 3.14 수정본을 이미 설치한 경우
------------------------------------------
1. 실행 중인 3_start_server.bat 창에서 Ctrl+C를 눌러 서버를 끕니다.
2. 이 ZIP의 내용을 기존 폴더에 덮어씁니다.
3. 기존 .venv314 폴더는 삭제하지 않아도 됩니다. 새 서버에서는 사용하지 않습니다.
4. 1_setup_server.bat를 실행해 새 .venv311 환경을 설치합니다.
5. 고품질 사진 복원을 사용하려면 2_set_replicate_token.bat를 한 번 실행합니다.
6. 음악·자동 문구·게시글 추천을 사용하려면 2_set_gemini_key.bat를 한 번 실행합니다.
7. 3_start_server.bat를 다시 실행합니다.

처음 한 번
----------
1. 압축을 새 폴더에 풉니다.
2. AIIntegratedServer 폴더를 엽니다.
3. 1_setup_server.bat를 더블클릭합니다.
4. SETUP COMPLETED SUCCESSFULLY가 나올 때까지 기다립니다.
5. 사진 복원을 위해 2_set_replicate_token.bat를 실행합니다.
6. Gemini 추천 기능을 사용할 때 2_set_gemini_key.bat를 실행합니다.

프로그램을 사용할 때마다
------------------------
1. AIIntegratedServer\3_start_server.bat를 실행합니다.
2. 검은 서버 창을 닫지 않습니다.
3. ImageEditor.sln을 Visual Studio 2022로 열어 실행합니다.

확인 방법
--------
- AIIntegratedServer\4_check_server.bat를 실행합니다.
- Server connection OK가 나오면 정상입니다.
- 서버 주소는 http://127.0.0.1:8000 입니다.

참고
----
- 설치 파일은 Python 3.11.9 전용 .venv311 폴더를 자동으로 만듭니다.
- AI 모델은 한글 프로젝트 경로 오류를 막기 위해
  %LOCALAPPDATA%\ImageEditorAI\models에 저장됩니다.
- 기존 AIIntegratedServer\models에 받은 모델은 새 위치로 자동 복사됩니다.
- 그래픽카드가 없어도 됩니다. 사진 복원은 Replicate 클라우드 GPU를 사용하고,
  나머지 로컬 AI 기능과 복원 실패 시 대체 처리는 CPU로 실행합니다.
- 최초 패키지 설치와 최초 모델 다운로드는 용량이 커서 오래 걸릴 수 있습니다.
- 물체 제거와 배경 제거는 별도 API 비용이 없습니다.
- 사진 복원은 Replicate를 호출할 때마다 크레딧을 사용합니다.
  토큰·인터넷·크레딧 오류가 나면 기존 로컬 CPU 복원으로 자동 전환합니다.
- 음악·자동 문구·게시글 추천은 Gemini API 키와 인터넷 연결이 필요합니다.
- Replicate 토큰과 Gemini 키는 프로젝트 밖의 사용자 전용 설정 폴더에 저장됩니다.
- 3.2 수정본부터 세피아 사진도 흑백 계열로 판별해 컬러 복원하고,
  얼굴과 하단 글자를 보호하면서 길고 가는 균열을 더 강하게 복원합니다.
- 이미지 열기 후 작은 사진이 과도하게 확대되거나 프로그램 창 크기가 바뀌는
  문제를 수정했습니다.
- 설치를 중간에 취소해 계속 오류가 나면 .venv311 폴더만 삭제한 뒤
  1_setup_server.bat를 다시 실행합니다.
