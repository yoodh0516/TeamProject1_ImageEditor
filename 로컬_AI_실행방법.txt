ImageEditor + FastAPI 통합 AI 서버: 처음부터 실행하는 방법
========================================================

완성된 구조
- C# ImageEditor: 화면과 편집 기능
- Python FastAPI: AIIntegratedServer\server.py
- 연결 주소: http://127.0.0.1:8000
- 로컬 CPU 기능: 물체 선택/제거, 배경 제거, 사진 복원 실패 시 대체 처리
- 클라우드 GPU 기능: Replicate를 이용한 오래된 사진 고품질 복원
- 선택 기능: Gemini를 이용한 음악·자동 문구·게시글 추천


0단계: 기존 서버 정리
---------------------
기존에 port 8000 또는 8001을 쓰던 Python 서버 창이 있다면 Ctrl+C로 종료합니다.
이 수정본은 8000번 서버 하나만 사용합니다.


1단계: Python 3.11.9 확인 (처음 한 번)
-----------------------------------
1. Python 3.11.9 64-bit를 설치합니다.
2. 명령 프롬프트(cmd)를 새로 열어 다음을 입력합니다.

   py -3.11 --version

3. Python 3.11.9가 나오면 성공입니다.
4. 명령을 찾지 못하면 Python 3.11.9 64-bit를 다시 설치하고
   설치 화면에서 "Add python.exe to PATH"를 체크합니다.


2단계: 서버 패키지 설치 (처음 한 번)
------------------------------------
1. 압축을 푼 프로젝트에서 AIIntegratedServer 폴더를 엽니다.
2. 1_setup_server.bat를 더블클릭합니다.
3. 설치 완료 문구가 나올 때까지 기다립니다.

설치되는 주요 항목:
- FastAPI / Uvicorn
- Python 3.11용 CPU PyTorch
- Ultralytics MobileSAM
- LaMa 물체 제거 모델(서버에서 직접 실행)
- U2NetP 배경 제거 모델(ONNX Runtime으로 직접 실행)
- OpenCV 복원 모델 실행 환경
- MediaPipe 원거리 얼굴 검출 모델(커뮤니티 필터 자동 맞춤)

패키지 용량이 크므로 처음 설치는 인터넷 속도에 따라 오래 걸릴 수 있습니다.
.venv311 폴더에만 설치되므로 다른 Python 프로젝트와 섞이지 않습니다.


3단계: Replicate 토큰 설정 (고품질 사진 복원)
------------------------------------------------
1. Replicate에서 r8_로 시작하는 API 토큰을 발급합니다.
2. AIIntegratedServer\2_set_replicate_token.bat를 실행합니다.
3. 토큰을 붙여넣고 Enter를 누릅니다.
4. "Replicate API token saved"가 나오면 바로 사용할 수 있습니다.

토큰은 소스코드나 ZIP이 아닌 사용자 전용 ImageEditorAI 설정 폴더에 저장됩니다.
서버를 다시 시작할 필요는 없습니다. Replicate 복원은 실행할 때마다 계정
크레딧을 사용합니다. 토큰·인터넷·크레딧 오류 시 로컬 CPU로 자동 대체됩니다.


선택 단계: Gemini 키 설정 (추천 기능을 쓸 때)
--------------------------------------------------
물체 제거, 배경 제거, 사진 복원만 사용한다면 Gemini 설정은 건너뛰어도 됩니다.

1. Google AI Studio에서 Gemini API 키를 발급합니다.
2. AIIntegratedServer\2_set_gemini_key.bat를 실행합니다.
3. 키를 붙여넣고 Enter를 누릅니다.
4. "Gemini API key check OK"가 나오면 바로 사용할 수 있습니다.

키는 소스코드나 ZIP에 저장되지 않고 사용자 전용 ImageEditorAI 설정 폴더에
저장됩니다.
키를 설정한 뒤 서버를 다시 시작할 필요는 없습니다.


4단계: FastAPI 서버 실행 (프로그램을 쓸 때마다)
------------------------------------------------
방법 A - 가장 쉬운 방법:
1. AIIntegratedServer\3_start_server.bat를 더블클릭합니다.
2. "Uvicorn running on http://127.0.0.1:8000"이 나오면 성공입니다.
3. ImageEditor를 사용하는 동안 이 검은 창을 닫지 않습니다.

방법 B - 직접 명령어로 실행:
1. AIIntegratedServer 폴더에서 cmd를 엽니다.
2. 다음 명령을 차례로 입력합니다.

   .venv311\Scripts\activate
   python server.py

서버를 끄려면 서버 창에서 Ctrl+C를 누릅니다.


5단계: 서버 연결 확인
---------------------
1. AIIntegratedServer\4_check_server.bat를 실행합니다.
2. "서버 연결 성공"이 나오면 정상입니다.
3. 웹브라우저에서 다음 주소를 직접 열어도 됩니다.

   http://127.0.0.1:8000/health
   http://127.0.0.1:8000/docs


6단계: C# ImageEditor 실행
-------------------------
1. Visual Studio 2022를 실행합니다.
2. ImageEditor.sln을 엽니다.
3. NuGet 패키지 복원이 끝날 때까지 기다립니다.
4. F5 또는 시작 버튼을 누릅니다.
5. 로그인 DB를 사용하지 않는 경우 "로그인 없이 시작"을 선택할 수 있습니다.
6. 이미지를 불러오고 AI 메뉴에서 기능을 실행합니다.


7단계: AI 기능 사용
-------------------
- 물체 제거 포인터 모드: 지울 물체를 한 번 클릭 → 마스크 확인 → 이 영역 지우기
- 물체 제거 드래그 모드: 물체를 사각형으로 선택 → 마스크 확인 → 이 영역 지우기
- AI 배경 제거: 결과 확인 → 적용하기 → 투명 유지 시 PNG로 저장
- AI 오래된 사진 복원: 복원 시작 → Before/After 확인 → 결과 적용
  · Replicate FLUX Kontext가 긁힘·손상·색상·얼굴을 고품질 복원합니다.
  · 오류 시 기존 세피아 판별·균열 복원 로컬 CPU 방식으로 자동 대체됩니다.
  · 비교 창 위쪽에서 실제 사용된 복원 방식을 확인할 수 있습니다.
- AI 음악 추천: Gemini 키가 설정된 경우 현재 이미지에 맞는 노래 1곡 추천
- 기존 자동 문구 추천: 이미지에 어울리는 짧은 문구 추천
- AI 게시글·해시태그 추천: 플랫폼·말투·길이에 맞춘 게시글 2문장과 해시태그 추천
- 커뮤니티 필터: 얼굴 필터 선택 → 얼굴 위치·크기·기울기 자동 맞춤 → 필요 시 수동 조정 → 적용


처음 기능을 누를 때 정상적으로 오래 걸리는 이유
---------------------------------------------
- MobileSAM, LaMa, U2NetP를 최초 1회 내려받습니다.
- 모델은 한글 경로 문제를 막기 위해 %LOCALAPPDATA%\ImageEditorAI\models에 저장됩니다.
- 그래픽카드 대신 CPU를 사용하므로 큰 이미지는 수십 초~수분 걸릴 수 있습니다.
- 두 번째 실행부터는 내려받은 모델을 재사용합니다.


비용과 인터넷 사용
------------------
- 물체 제거 / 배경 제거: 로컬 CPU 실행, 별도 호출 비용 없음
- 커뮤니티 얼굴 자동 맞춤: 로컬 CPU 실행, 별도 호출 비용 없음
- 오래된 사진 복원: Replicate API 호출, 실행마다 Replicate 크레딧 사용
- Replicate 실패 시 실행되는 로컬 CPU 대체 복원: 별도 호출 비용 없음
- 음악·자동 문구·게시글 추천: Gemini API 호출, 인터넷과 API 키 필요, Google 계정 요금/할당량 정책 적용
- 최초 모델 다운로드에는 인터넷이 필요합니다.


문제 해결
---------
1. "AI 서버가 실행되지 않았습니다"
   → 3_start_server.bat를 먼저 실행하고 창을 열어 둡니다.

2. "Python 3.11.9 64-bit를 찾지 못했습니다"
   → cmd에서 py -3.11 --version을 확인합니다.
   → 명령을 찾지 못하면 Python 3.11.9 64-bit를 PATH 옵션과 함께 다시 설치합니다.

3. 패키지 설치를 중간에 취소한 뒤 계속 오류가 납니다
   → AIIntegratedServer 폴더의 .venv311 폴더만 삭제합니다.
   → 1_setup_server.bat를 다시 실행합니다.

4. "address already in use" 또는 port 8000 오류
   → 기존 Python 서버 창을 Ctrl+C로 끄고 다시 실행합니다.
   → cmd에서 netstat -ano | findstr :8000 으로 사용 중인 프로세스를 확인할 수 있습니다.

5. 첫 AI 처리 중 다운로드 오류
   → 인터넷 연결을 확인한 뒤 같은 기능을 다시 실행합니다.

6. 사진 복원 결과에 로컬 CPU 대체 복원이라고 나옵니다
   → 2_set_replicate_token.bat를 실행했는지 확인합니다.
   → Replicate 토큰, 인터넷 연결, 크레딧 잔액을 확인합니다.

7. Gemini 추천 기능만 실패
   → 새 2_set_gemini_key.bat를 다시 실행합니다. 서버 재시작은 필요 없습니다.
   → Gemini 키의 사용 가능 상태와 할당량을 확인합니다.

8. 자세한 Python 오류 확인
   → AIIntegratedServer\server.log의 마지막 내용을 확인합니다.


중요
----
- server.py 안에 Replicate 토큰이나 Gemini 키를 직접 적지 마세요.
- .venv311과 내려받은 모델은 ZIP에 포함되지 않습니다. 각 PC에서 한 번 설치합니다.
- AI 결과는 모델의 추정이므로 실제 배경, 물체, 원본 색상과 다를 수 있습니다.
